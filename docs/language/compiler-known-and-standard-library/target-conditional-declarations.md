# Target-conditional declarations

A target-conditional declaration is available according to the selected target profile.
The definition and checking rules are in
[Target-conditional declarations](../targets-layout-abi-and-raw-memory/target-constraints-and-gates.md#target-conditional-declarations).

Those rules cover availability checks, disabled module contributions, generic instantiation, static instance identity,
and target-property dependencies in compiled interfaces.
[Target profiles and properties](../targets-layout-abi-and-raw-memory/target-profiles-and-properties.md) defines the
properties used by availability expressions.
