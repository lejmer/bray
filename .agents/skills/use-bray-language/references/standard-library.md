# Standard Library

Bray's standard library is the ordinary `std` package. It provides public modules for common data handling, memory, concurrency, I/O, platform services, interoperability, and testing. The package is explicit rather than ambient, and selected declarations receive compiler-recognized behavior only through stable declaration identity.

**General specifications:** [Standard-library declarations](https://github.com/lejmer/bray/blob/develop/docs/language/compiler-known-and-standard-library/standard-library-declarations.md), [standard-library recognition](https://github.com/lejmer/bray/blob/develop/docs/language/compiler-known-and-standard-library/standard-library-recognition.md), and [recognized operations](https://github.com/lejmer/bray/blob/develop/docs/language/compiler-known-and-standard-library/recognized-standard-library-operations.md)

For portable I/O, use `print` and `print_line` for ordinary text output. They accept `string` directly, and callers can ignore or handle their `IoError` result. Use `write_all` and `read_exact` or their async forms when a complete borrowed byte range and exact failure progress matter. Use individual reader and writer operations when handling partial transfers directly. Buffered streams coalesce small writes without implicit resource flushes and bypass empty staging storage for transfers at least as large as its capacity. Filesystem resources are owned, paths preserve target-native text, and operations that can block a native thread require `blocking_execution()`. Each standard stream owns one guard per logical operation, while generic readers, writers, and buffering add no stream lock. See [I/O and platform services][io-platform] for the transfer, atomicity, and cleanup contract.

`std.platform` is an internal implementation module, not part of the public standard-library surface. The compiler-provided `core` namespace is also separate from `std`. Consult [compiler-known declarations](compiler-known.md) when a task concerns protected representations or compiler-provided operations rather than ordinary library APIs.

[io-platform]: https://github.com/lejmer/bray/blob/develop/docs/language/io-and-platform-services.md

**Remember:** Start with the module group that owns the operation and read its linked specification. A declaration's `std` spelling does not imply compiler recognition.
